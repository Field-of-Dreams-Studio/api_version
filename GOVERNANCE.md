# av Governance

This repository is a proc-macro utility crate used across the Hotaru project.
All files and directories in this repository belong to that scope.

Current role eligibility, appointments, ownership, primary reviewers, and AI
tiers are maintained in the canonical
[Hotaru governance registry](https://github.com/Field-of-Dream-Studio/hotaru/blob/master/GOVERNANCE.md).
This repository follows the
[FDS Code Governance Policy](https://github.com/Field-of-Dream-Studio/hotaru/blob/master/POLICY.md).

For the contributor-facing workflow, see [CONTRIBUTING.md](./CONTRIBUTING.md).

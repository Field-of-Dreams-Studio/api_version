# Contributing to av

Contributions to `av` follow
[Hotaru's contribution guide](https://github.com/Field-of-Dream-Studio/hotaru/blob/master/CONTRIBUTING.md),
including its contributor workflow and code standards. See
[GOVERNANCE.md](./GOVERNANCE.md) for this repository's governed scope and the
applicable policy.

## Current status

- 0.2 is in flight: the previous `;`-separated multi-entry `#[ver]` form is
  removed, and five new attribute macros (`#[verlog]`, `#[safety]`,
  `#[panics]`, `#[author]`, `#[cite]`) are being introduced.
- API is not yet frozen on the `0.2-update` branch; expect breaking changes
  between pre-release tags until the 0.2.0 release lands.
